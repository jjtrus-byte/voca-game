# 영어-한글 단어 맞추기 게임

이 프로젝트는 Next.js를 사용하여 영어 단어와 한글 뜻을 사진으로 찍거나 직접 입력하여 등록하고, 등록된 단어들로 맞추기 퀴즈 게임을 즐길 수 있는 웹 앱입니다.

## 기능

- 카메라로 사진 촬영
- OCR (광학 문자 인식)으로 텍스트 추출
- 단어 직접 입력
- 단어 저장 (localStorage)
- 맞추기 퀴즈 게임

## 설치 및 실행

1. 의존성 설치:
   ```
   npm install
   ```

2. 개발 서버 실행:
   ```
   npm run dev
   ```

3. 브라우저에서 http://localhost:3000 접속

## 사용법

1. "카메라 시작" 버튼을 클릭하여 카메라를 활성화합니다.
2. 단어와 뜻이 적힌 종이를 카메라에 비추고 "사진 촬영 및 OCR" 버튼을 클릭합니다.
3. OCR로 추출된 텍스트가 입력 필드에 자동으로 채워집니다 (수정 가능).
4. "단어 저장" 버튼으로 단어를 저장합니다.
5. 등록된 단어들이 목록에 표시됩니다.
6. "퀴즈 시작" 버튼으로 게임을 시작합니다.
7. 영어 단어가 표시되면 한글 뜻을 입력하여 맞춰보세요.

## 주의사항

- 카메라 권한이 필요합니다.
- OCR 정확도는 사진 품질에 따라 다릅니다.
- 데이터는 브라우저의 localStorage에 저장됩니다.
